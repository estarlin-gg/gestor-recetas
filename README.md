# Sistema de Gestión de Recetas Médicas

Este sistema permite gestionar recetas médicas, permitiendo a los usuarios realizar operaciones CRUD (Crear, Leer, Actualizar, Eliminar) sobre las recetas. El sistema muestra información de las recetas, incluyendo la fecha de emisión y los medicamentos prescritos. Además, la aplicación es totalmente responsive y está diseñada utilizando el patrón MVC de ASP.NET para organizar el código de manera eficiente.

## Tecnologías Utilizadas

### Backend:
- **ASP.NET MVC**: Framework para crear la aplicación web con arquitectura Model-View-Controller (MVC).
- **SQL Server**: Base de datos utilizada para almacenar la información de las recetas médicas.

### Frontend:
- **Bootstrap**: Framework de CSS para el diseño responsivo y la interfaz de usuario.

## Funcionalidades

- **Crear Receta**: Permite crear nuevas recetas médicas con los detalles del medicamento y la fecha de emisión.
- **Leer Receta**: Visualiza las recetas existentes, mostrando los medicamentos prescritos y la fecha en que fueron emitidas.
- **Actualizar Receta**: Permite actualizar la información de una receta ya existente.
- **Eliminar Receta**: Permite eliminar recetas médicas de la base de datos.
